---
title: Manual setup
description: Run llama-dash from source against an existing llama-swap instance.
---

Run llama-dash directly with Node when you already have a llama-swap instance, or you want a development setup.

## Requirements

- Node 24+
- [pnpm](https://pnpm.io)
- A reachable llama-swap instance

## Install

### Configure the environment [step]

```bash
cp .env.example .env
```

Edit `.env` and set `INFERENCE_BASE_URL` to point at your llama-swap instance (default `http://localhost:8080`). Set `BETTER_AUTH_SECRET` to the output of `openssl rand -base64 33`. Leave `BETTER_AUTH_URL` blank for local development, or set it to `http://localhost:5173` when testing passkeys locally. See [Configuration](/docs/getting-started/configuration) for the full list of variables.

### Install dependencies [step]

```bash
pnpm install
```

llama-dash creates the SQLite database at `data/dash.db` and applies migrations when the server starts. You can also run `pnpm db:migrate` manually before startup if needed. To use the dashboard config editor in this setup, set `INFERENCE_CONFIG_FILE` to the absolute path of your llama-swap `config.yaml`.

### Start the dev server [step]

```bash
pnpm dev
```

The dev server runs on `http://localhost:5173`.

<Callout type="info">
  The development server listens on `5173`; the production Docker image and the
  diagrams in these docs use `3000`. Adjust client base URLs to match how you run it.
</Callout>
